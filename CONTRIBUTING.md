# Contributing

Thank you for helping improve this Forgotten Portal writeup.

## Scope

Contributions are welcome for:

- Documentation corrections and clarity improvements.
- Broken links, incorrect references, and Markdown formatting.
- MITRE ATT&CK mapping feedback supported by authoritative sources.
- Accessibility improvements to the repository content.

## Before You Submit

- Keep changes focused on this lab and its documented evidence.
- Do not add credentials, private keys, tokens, personal data, or unredacted sensitive information.
- Preserve the existing evidence and report files unless a change is explicitly required.
- Write documentation in English.

## Pull Requests

1. Create a branch from `main`.
2. Make a focused change and verify all edited links and Markdown references.
3. Describe what changed and why in the pull request.
4. Reference the relevant evidence or authoritative source for technical corrections.

## Reporting Issues

Open an issue with a concise description, the affected file or section, and the proposed correction. Do not publish sensitive information in issues or pull requests.
